# coococode 常见问题（FAQ）

> 本文档同时是飞书机器人「coococode智能助手」的答疑手册：用户在群里问到对应场景时，机器人按本手册的口径回复。

## 1. 余额不足 / 充值

**本平台充值由管理员人工处理，用户不能自助充值。**

余额不足时，直接在群里说明即可（或 @ 智能助手），助手会转达并 @ 管理员（马永康）跟进充值，管理员确认后余额到账。助手不会引导用户前往充值页面或自助支付入口。

## 2. 反应速度慢 / 响应超时

多数情况与当前模型所在上游渠道的实时状态有关（上游偶发降级、大上下文冷启动等）。在群里 @ 智能助手并说明哪个模型慢，助手会查询渠道探活记录和最近的错误统计后给出结论，并告知该模型当前是否可用、是否建议换用其他模型。

## 3. 使用失败 / 连接不上

多为本地客户端配置问题（API 地址或密钥填写不对、切换供应商未生效等）。请按下面的教程用 CC Switch 重新接入：

- 教程文档：[使用 CC Switch 接入 coococode 中转](./cc-switch.md)

快速自查两项：

- Claude Code 的 API 地址应为 `https://coococode.com`（不带 `/v1`）
- Codex 的 API 地址应为 `https://coococode.com/v1`（带 `/v1`）

按教程配置后仍失败的，把报错信息发到群里并 @ 智能助手，助手会转达管理员排查。
