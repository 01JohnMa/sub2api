# Coococode 可见品牌清理设计

## 目标

在保留最新上游后端和前端兼容机制的前提下，删除产品界面中用户可见的 `Sub2API` / `su2api` 品牌信息，统一显示为 `coococode`。

## 范围

- 将页面标题、说明、表单占位符、引导文案、下载文件名和示例中的可见品牌名替换为 `coococode`。
- 移除管理界面中指向 Sub2API 仓库或推广站点的可见入口；功能所需的上游版本检查和文档来源可在内部继续使用。
- 将登录、注册、验证、法律文档等页面的默认站点名统一为 `coococode`。
- 保留现有 Coococode 首页、管理界面、CPA 管理入口和最新上游功能。

## 明确不改

- 不修改 `backend/`、CPA、数据库、API 合同、认证和 Nginx。
- 不重命名兼容性标识，包括 npm 包名、localStorage/IndexedDB 键、WebSocket 子协议、导入数据类型、数据库默认名和代码内部测试夹具。
- 不删除功能所依赖的上游仓库地址、合规文档地址或第三方服务地址；只避免把它们作为产品品牌入口展示给普通用户。

## 验收标准

- 面向用户的运行时界面不再显示 `Sub2API` / `su2api`。
- 内部兼容标识保持原值，后端相对最新上游仍为零差异。
- 运行品牌、标题和受影响页面的聚焦测试，并完成一次前端生产构建。
- 只读审查无 Critical / Important 后构建新镜像，仅重建 `sub2api`。
- 线上首页和管理界面显示 `coococode`，CPA、PostgreSQL、Redis 运行实例不变。

## 回滚

部署前镜像 `ghcr.io/01johnma/sub2api:ui-redesign-9231ab7` 作为回滚版本。
