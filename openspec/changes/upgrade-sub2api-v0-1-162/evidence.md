## Release Path Decision

- This customized branch will not use the tagged GoReleaser `release.yml` workflow. Its manual-dispatch frontend checkout is not pinned to the selected tag and therefore cannot prove a single-source frontend/backend image for this integration.
- The repository-specific `coococode-image.yml` builds the root Dockerfile from the workflow ref and stamps `COMMIT=${{ github.sha }}`. Because GitHub only permits manual dispatch when the workflow exists on the default branch, this upgrade branch is explicitly included in the workflow's `push` trigger. The reviewed merge commit was pushed through that trigger, and the resulting workflow SHA and immutable GHCR digest were verified before production preflight.
- The upstream compose template's local `sub2api:latest` image and relaxed URL defaults are not the production deployment source. Candidate and production checks must keep the current explicit GHCR image and the existing production URL/client-IP security settings.
